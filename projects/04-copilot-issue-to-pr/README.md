# GitHub Copilot — Issue → PR

## Objetivo
Delegar uma mudança a partir de uma issue e validar o resultado no fluxo do GitHub.

## Entregáveis
- `requirements.md` preenchido a partir do template;
- design técnico curto;
- plano de tarefas;
- implementação versionada;
- testes automatizados;
- relatório de validação;
- registro de riscos e rollback.

## Regras do laboratório
1. Comece em branch/ambiente isolado.
2. Não forneça segredos reais ao agente.
3. Exija plano antes de mudanças grandes.
4. Use critérios de aceitação observáveis.
5. Execute testes e revise o diff antes de considerar concluído.
6. Mantenha aprovação humana para ações de alto impacto.
