# AGENTS.md

## Objetivo do repositório
Materiais complementares do livro IA para Devs.

## Regras para agentes
- Leia o README da pasta antes de editar.
- Prefira mudanças pequenas, reversíveis e cobertas por testes.
- Nunca inclua tokens, senhas, chaves ou dados pessoais em commits.
- Não altere comandos de segurança para ampliar permissões sem justificativa explícita.
- Ao modificar um exemplo, atualize a documentação correspondente.
- Para APIs e CLIs de fornecedores, confirme a versão atual antes de assumir sintaxe.

## Definition of Done
- código formatado;
- testes relevantes executados;
- nenhum segredo versionado;
- README atualizado quando necessário;
- riscos e limitações registrados.
