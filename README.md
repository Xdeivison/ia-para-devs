# IA para Devs — materiais complementares

Repositório complementar do livro **IA para Devs — Agentes, MCP, Prompt Engineering e a Nova Stack do Desenvolvedor na Era da IA**, de **Deivison Viana Andrade**.

Portal canônico: https://www.deivisonviana.com/ia-para-devs

## Objetivo

Este pacote concentra exemplos que devem continuar vivos mesmo quando CLIs, modelos e APIs mudarem. Antes de executar comandos de instalação ou APIs de fornecedores, confira a documentação oficial indicada no livro e no portal.

## Estrutura

- `prompts/`: prompts reutilizáveis para delegação agentiva.
- `design-docs/`: templates de requisitos e desenho técnico.
- `mcp/`: servidor MCP didático e configurações.
- `skills/`: Agent Skills portáveis.
- `evals/`: conjunto mínimo para regressão de agentes.
- `docker/`: ambiente local para exercícios.
- `projects/`: 12 projetos do livro e o projeto final.
- `assets/diagrams/`: diagramas do manuscrito.

## Regra de ouro

Não dê a um agente mais permissão do que ele precisa. Comece em ambiente descartável, versionado e testável; mantenha revisão humana para ações de alto impacto.
