# MCP Toolbox — Python

Exemplo mínimo para estudar `tools`, `resources`, `prompts`, validação de caminhos e transporte remoto.

## Execução
1. Crie um ambiente virtual.
2. Instale o projeto com `pip install -e .`.
3. Execute `python server.py`.
4. Cadastre o endpoint no cliente MCP usado no laboratório.

> A interface do SDK pode mudar. Confirme a documentação oficial antes de copiar a sintaxe para produção.
